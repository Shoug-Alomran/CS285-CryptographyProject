§ 00 · Abstract

The security rests on a function that is easy to compute and hard to invert.

The project shows how two participants can establish a shared secret using public-key cryptography. It implements the Diffie–Hellman key exchange, so a key can be agreed over an insecure channel without either private value ever being sent.

The derived key then drives message encryption and decryption. The program validates every input and offers two ways to explore it: a guided numerical example and an interactive live mode.

Computing αx mod q is fast. Going the other way, recovering x from the result, is the discrete logarithm problem, which is infeasible in practice when q is large.
